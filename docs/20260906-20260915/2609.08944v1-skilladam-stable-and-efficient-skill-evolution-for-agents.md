## 摘要
智能体技能提供了一种轻量级方式，为冻结的语言模型智能体配备领域知识和过程性指导，但获取高质量技能仍然成本高昂且难以规模化。专家撰写的技能需要大量人力。近期的技能自演化方法自动化了一个迭代循环，利用执行反馈来修正技能，但其启发式更新策略往往导致优化不稳定和迭代效率低。我们识别出实现稳定且高效的技能自演化所面临的两个挑战。方向稳定性要求有效修正能够累积，而不是被迭代局部反馈覆盖。更新自适应性要求每次修订的范围能够反映近期案例级改进的一致性。我们提出 SkillAdam，一个受 Adam 启发的框架，用于优化离散且不可微的技能文档。作为 Adam 一阶矩的功能类似物，优化记忆记录已识别的问题以及先前解决尝试的结果，以稳定更新方向。作为 Adam 二阶矩的功能类似物，波动驱动的编辑预算跟踪近期案例级改进的历史加权变化，并自适应地控制更新幅度。在涵盖短时程和长时程任务的七个基准上，SkillAdam 实现了最先进的性能，并具有更稳定的优化动态。与先前方法相比，它还能以显著更少的优化迭代次数和更低成本获得更强的技能。代码仓库：https://github.com/ruc-datalab/SkillAdam

## Abstract
Agent skills provide a lightweight way to equip frozen language-model agents with domain knowledge and procedural guidance, yet obtaining high-quality skills remains costly and difficult to scale. Expert-written skills require substantial human effort. Recent skill self-evolution methods automate an iterative loop that uses execution feedback to revise skills, but their heuristic update strategies often yield unstable optimization and low iteration efficiency. We identify two challenges in realizing stable and efficient skill self-evolution. Direction Stability requires effective corrections to accumulate rather than be overwritten by iteration-local feedback. Update Adaptivity requires the scope of each revision to reflect the consistency of recent case-level improvements. We introduce SkillAdam, an Adam-inspired framework for optimizing discrete and non-differentiable skill documents. As a functional analogue of Adam's first moment, an optimization memory records identified problems and the outcomes of prior solution attempts to stabilize the update direction. As a functional analogue of Adam's second moment, a volatility-driven edit budget tracks the history-weighted variation of recent case-level improvements and adaptively controls the update magnitude. Across seven benchmarks that span short- and long-horizon tasks, SkillAdam achieves state-of-the-art performance with more stable optimization dynamics. It also obtains stronger skills with substantially fewer optimization iterations and lower cost than prior methods. Code repository: https://github.com/ruc-datalab/SkillAdam

## 1. 核心问题与整体含义

- **研究背景**：LLM 智能体在多步规划与工具使用上表现出色，但在领域特定场景（如多城市旅行规划、数据准备）中常因通用能力无法满足长尾需求而表现不佳。Anthropic 提出的 **Agent Skills** 以模块化指令包形式为冻结模型注入领域知识，但高质量技能难以规模化获取。
- **核心痛点**：
  - 专家手写技能耗时耗力；LLM 一次性生成的技能往往无效（SkillAxe 指出需反复精炼）。
  - 现有技能自演化方法依赖启发式更新策略，存在两个关键挑战：
    - **方向稳定性（Direction Stability）**：每次迭代仅基于有限案例反馈，连续修订可能互相抵消、覆盖此前有效修正。
    - **更新自适应性（Update Adaptivity）**：修订幅度应依据近期案例级改进的一致性来决定——改进不一致时应限制编辑范围，改进一致时方可扩大修改。
- **整体含义**：论文将 Adam 优化器的两大设计原则（一阶矩稳定方向、二阶矩自适应步长）**功能性地**迁移到离散、不可微的技能文档空间，提出 SkillAdam 框架，旨在实现稳定且高效的技能自演化。

## 2. 方法论

### 核心思想
- 技能 $S$ 是 Markdown 格式的自然语言指令文档，优化目标为 $S^* = \arg\max_{S \in \mathcal{S}} J(S)$，其中 $J(S)$ 由领域评估器返回的指标向量聚合而成。
- 不做数值梯度计算，而是构造**语言空间的状态**，扮演与 Adam 一阶矩、二阶矩相同的优化角色（功能对应而非数值对应）。

### 关键技术组件

- **轨迹引导的初始化（Trajectory-Informed Initialization）**：
  - 从执行轨迹与评估反馈中构建初始技能 $S_0$，而非随机初始化。

- **优化记忆 = 演化问题追踪器（Evolving Issue Tracker, EIT）**：
  - 功能类比 Adam 的一阶矩 $m_t^{\text{Adam}} \leftrightarrow M_t$。
  - 维护结构化问题条目 $M_t = \{I_j | j \in \mathcal{J}_t\}$，每条 $I_j = (p_j, z_j, A_j)$，其中 $(p_j, z_j)$ 为错误模式及其当前状态，$A_j$ 记录历史解决尝试及结果。
  - 每轮候选评估后通过 LLM 更新函数 $U_{\text{EIT}}$ 演化：关联新失败到已有问题、必要时新建条目、记录修改结果、同一失败复现时重新打开问题。

- **波动驱动编辑预算（Volatility-driven Edit Budget）**：
  - 功能类比 Adam 的二阶矩 $v_t^{\text{Adam}} \leftrightarrow V_t$，有效步长 $\alpha_t^{\text{eff}} \leftrightarrow \sigma_{t+1}$。
  - 案例级改进：$\delta_{t,i} = s(E_{t,i}^{\text{val}}) - s(E_{t,i}^{\text{roll}})$
  - 平均改进：$\bar{\delta}_t = \frac{1}{|B_t|}\sum_{d_i \in B_t}\delta_{t,i}$
  - 当前波动：$\hat{V}_t = \frac{1}{|B_t|-1}\sum(\delta_{t,i}-\bar{\delta}_t)^2$（不足两个案例时取 0）
  - 历史加权波动：$V_t = \beta_2 V_{t-1} + (1-\beta_2)\hat{V}_t$，$V_0=0$
  - 编辑预算：$\sigma_{t+1} = \max\left(b_{\min}, \sqrt{b_{\text{base}}\left[1-\text{clip}\left(\frac{V_t}{V_{\max}},0,1\right)\right]}\right)$
  - 波动高 → 预算小（限制修改）；波动低 → 允许更大范围修改。

### 算法流程（Algorithm 1）
1. 收集初始化数据 $(T_0, F_0)$，LLM 生成 $S_0$；初始化 $M_0=\emptyset$，$V_0=0$，$\sigma_1=b_{\text{base}}$。
2. 对 $t=1,\dots,T_{\max}$：
   - 采样小批量 $B_t$，执行当前技能得轨迹 $T_t$ 与反馈 $F_t^{\text{roll}}$。
   - 补丁生成器 $G_{\text{LLM}}(S_{t-1}, T_t, F_t^{\text{roll}}, M_{t-1}, \sigma_t)$ 产生补丁 $g_t$，应用得候选 $\tilde{S}_t$。
   - 候选在相同案例上评估得 $F_t^{\text{val}}$，接受门 $a_t = G_\theta(\cdot) \in \{0,1\}$ 决定是否替换当前技能。
   - 更新 EIT：$M_t = U_{\text{EIT}}(M_{t-1}, T_t, F_t^{\text{roll}}, g_t, F_t^{\text{val}}, a_t)$。
   - 计算 $\delta_{t,i}$、$\hat{V}_t$、$V_t$，并据此确定 $\sigma_{t+1}$。
3. 返回最终技能 $S_{T_{\max}}$。

## 6. 主要结论

- **性能**：
  - 在 6 个短时程基准与 4 个长时程 DeepPlanning 切片上，SkillAdam 在绝大多数切片取得最优或并列最优，相对 NoSkill 与 LLMSkill 有显著提升，且整体优于 Trace2Skill、TextGrad、GEPA、SkillOpt。
  - 相对最接近的基线 SkillOpt，SkillAdam 在长时程任务（尤其 DeepPlanning）上优势更明显，说明轨迹引导初始化与波动感知编辑在长程、多步场景中收益更大。
- **消融**：
  - 去除波动驱动编辑预算（−B）后性能下降，说明固定/启发式编辑幅度在波动期会破坏已有有效修正。
  - 进一步去除 EIT（−B−M）后性能继续下降，验证一阶矩式问题追踪对方向稳定性的独立贡献；两组件作用互补而非冗余。
- **迁移性**：优化后的技能在更小的目标模型（GPT-5.4-mini）上仍保持较高 retention，说明技能文档捕获的是领域知识而非对特定模型的过拟合。
- **技能质量**：LLM 裁判在 6 个维度上普遍给 SkillAdam 技能更高分，尤其在"覆盖度""可操作性""内部一致性"上领先，与性能提升方向一致。
- **效率**：优化阶段 token 与 API 请求数相对 SkillOpt 降低约 2/3，且达到更高准确率，说明"更少但更精准的编辑"比"更多次小步试错"更高效。
- **优化动态**：SkillAdam 在准确率-迭代曲线上更早进入高位平台且波动更小；在准确率-token 曲线上单位 token 收益更高，呈现"少步大步 + 稳定方向"的特征。

- **评估依赖 LLM 裁判与闭源 API**：技能质量由 LLM 评分，性能依赖闭源模型，结果可复现性与长期可比性受限。
- **统计严谨性**：缺少多种子方差与显著性检验，部分切片样本量小（如 10 例），结论的稳健性有待加强。
- **通用性边界**：仅在智能体技能文档这一形态上验证，是否能推广到代码库、提示词、工具定义等其他"文本可优化对象"未做探索。

## 9. 启发与展望

- **"优化器原则 → 文本优化"是一条可复用的设计范式**：凡是在离散、不可微对象上做迭代改进，都可尝试把一阶矩（历史方向记忆）、二阶矩（波动自适应）等功能角色显式实现为外部结构。
- **稳定性优先于步长**：在噪声反馈环境下，先把方向稳住（EIT），再决定改多少（波动预算），可能比直接调大步长更有效。
- **成本与质量可兼得**：SkillAdam 表明"少而准"的编辑在 token 效率上优于"多而碎"的试错，这对长程智能体优化的工程落地有直接意义。
- **可迁移技能的价值**：技能在弱模型上保持较高 retention，意味着可以"强模型优化、弱模型部署"，为低成本部署提供路径。
- **未来方向**：可探索多文档/多技能联合演化、EIT 的自动剪枝与层级化、波动信号的贝叶斯/置信区间估计、以及引入多种子统计检验与更广泛的目标模型迁移矩阵。
