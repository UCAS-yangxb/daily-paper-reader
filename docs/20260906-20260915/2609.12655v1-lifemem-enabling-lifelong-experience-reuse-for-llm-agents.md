## 摘要
大型语言模型智能体被期望在其生命周期内通过复用过去经验，持续适应新任务和新环境。然而，现有基于记忆的智能体难以跨环境迁移可复用经验，并且随着经验积累会遭受灾难性遗忘。为应对这些挑战，我们提出 LifeMem，一个使智能体能够在多个环境间迁移知识的终身学习框架。在学习过程中，LifeMem 根据底层工作流对积累的交互轨迹进行聚类，以提取可复用技能。在推理时解决新任务时，智能体回忆相关技能和轨迹以指导动作。为验证我们的方法，我们在 10 个环境和超过 13k 个任务上进行了实验，并使用了 2k 条新标注的交互轨迹。结果表明，LifeMem 在终身学习中实现了有效的经验复用，既减少了对已学习任务的遗忘，又取得了更优的跨任务迁移。进一步分析揭示，任务流式到达会影响学习，而在记忆中整合结构相似的轨迹可提升性能。

## Abstract
Large language model agents are expected to continuously adapt to new tasks and environments over their lifetime by reusing past experience. However, existing memory-based agents struggle to transfer reusable experience across environments and suffer from catastrophic forgetting as experience accumulated. To address these challenges, we propose LifeMem, a lifelong learning framework that enables agents to transfer knowledge across multiple environments. During learning, LifeMem clusters accumulated interaction trajectories based on underlying workflows to extract reusable skills. When solving a new task at inference time, the agent recalls relevant skills and trajectories to guide actions. To validate our method, we conduct experiments across 10 environments and over 13k tasks with 2k newly annotated interaction trajectories. Results show that LifeMem enables effective experience reuse in lifelong learning, achieving both reduced forgetting on learned tasks and superior cross-task transfer. Further analysis reveals that task streaming impacts learning, while consolidating structurally similar trajectories within memory boosts performance.

# LifeMem 论文总结

## 1. 核心问题与整体含义

- **研究背景**：追求 AGI 需要能终身自主适应的智能体。LLM 智能体被期望跨具身控制、网页导航、工具使用等多个领域泛化，而无需针对每个环境重新设计。
- **核心问题**：在**跨环境（inter-environment）终身学习**设定下，智能体需从异构环境（动作空间与观测空间均不同）收集的交互轨迹中持续积累经验，但面临两大障碍：
  - **经验迁移困难**：轨迹级检索无法弥合动作空间不匹配；全局抽象技能会因未组织记忆池而引入严重跨环境噪声。
  - **灾难性遗忘**：随着记忆库增长，检索精度下降，早期环境经验被覆盖或干扰，导致性能退化。
- **整体含义**：论文提出 LifeMem 框架，通过"工作流聚类 + 技能蒸馏"的结构化记忆机制，使智能体在终身学习中既能减少已学任务遗忘，又能实现对新领域、新任务形式的零样本跨任务迁移。

## 2. 方法论

### 核心思想
- 将记忆建模为**动态组件**：初始化一次，随新经验增量更新，推理时查询。
- 关键创新：**按底层执行工作流而非表面语义相似度**组织轨迹，并在每个工作流簇内部**局部蒸馏**环境无关技能，避免全局抽象引入的跨环境噪声。

### 关键技术细节

- **记忆初始化**：
  - 用 LLM 将初始轨迹划分为若干工作流簇 $C = \{c_1, \dots, c_M\}$，为每簇生成描述 $d_i$，构成初始记忆。

- **记忆演化（工作流聚类）**：
  - 新轨迹 $\xi$ 到来时，检索 top-k 相关轨迹及其所属簇 $C_\xi$。
  - LLM 判断：(1) 若对齐现有簇则加入并更新描述；(2) 若不对齐则新建簇。
  - **几何多样性约束**：基于方向统计中的**平均合成向量长度（MRL）**衡量簇内结构同质性。将轨迹嵌入归一化为单位向量 $x_i$，定义方向集中度：
    $$R = \frac{1}{n}\sum_{i=1}^{n} x_i, \quad R \in [0,1]$$
    $R \to 1$ 表示高度同质（如模板重复），$R$ 低表示行为多样。
  - **自适应分裂条件**：当且仅当 $n > L$ 且 $R < \tau_{mrl}$ 时，簇被分裂为更细粒度子簇。实验中 $L=50$，$\tau_{mrl}=0.95$。

- **技能蒸馏**：
  - 对每个工作流簇 $c_i$，通过 LLM 提示过程 $f(\cdot)$ 蒸馏出环境不变的文本技能：$s_i = f(c_i)$。
  - 技能捕捉共享约束、逻辑依赖与通用执行原则，剥离低层环境细节。
  - 分层记忆表示为：$H = \{(c_i, s_i) \mid c_i \in C\}$。

- **推理阶段（双轨机制）**：
  - 检索 top-k 最相似的历史轨迹（同环境对齐，提供操作范例）。
  - 识别对应工作流簇并激活技能：$S_\xi = \{s_i \mid c_i \in C_\xi\}$。
  - 最终动作生成：$a = P_\theta(g, M_{act}, o)$，其中 $M_{act} = (\{\xi_j\}_{j=0}^{k-1}, S_\xi)$。

### 算法流程（文字说明）
1. 初始化：划分初始轨迹为工作流簇并生成描述。
2. 新轨迹到达 → 检索相关簇 → LLM 判断加入或新建。
3. 检查分裂条件（$n > L$ 且 $R < \tau_{mrl}$）→ 必要时分裂为 3–6 个更细簇。
4. 从每个簇蒸馏环境无关技能。
5. 推理时同时激活环境对齐轨迹与相关技能，指导动作生成。

- **零样本跨任务迁移**：在 FEVER 与 τ-bench airline 上均优于基线；仅提供抽象技能（无轨迹）时仍具迁移能力。

## 7. 优点

- **方法创新**：
  - 首次在跨环境终身学习设定下，按**底层工作流**而非语义相似度组织记忆，从根源上缓解跨环境检索干扰。
