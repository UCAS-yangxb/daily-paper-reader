## 摘要
递归自我改进（RSI）需要一种具体机制，使 AI 系统能够观察自身能力，并将这些证据转化为下一轮学习。我们提出 NeoHorse-1，这是一系列智能体原生模型，旨在通过智能体式后训练探索这一路径。我们的系统将异构模型池与智能路由相结合，记录每个用户轮次的预测能力需求、所选服务层级以及后续交互。这些记录被转化为训练样本，保留交错的推理、工具调用和 Harness 上下文，并通过结构验证、六维语义评估和子场景级标注进行准入。路由信号将监督微调组织为三阶段课程，并扩展至路由引导的同策略蒸馏，其中教师在同一课程进度下监督学生生成的响应。能力引导的分配随后将评估反馈转化为下一轮训练混合数据，从而闭合“评估—选择—更新”循环：在该循环中，系统学会做什么会塑造它下一步从什么中学习。在涵盖基于 Harness 的智能体、工具使用、编码和指令遵循的十一个基准上，后训练将 4B 的宏平均从 58.94 提升至 64.87，将 9B 的宏平均从 65.60 提升至 69.04，显著缩小了后训练 4B 模型与 9B 基础模型之间的总体差距。NeoHorse-1 为这一反馈驱动过程提供了初步原型，并指明了跨连续迭代实现 Harness 介导的 RSI 的路径。

## Abstract
Recursive self-improvement (RSI) requires a concrete mechanism through which an AI system observes its capabilities and converts that evidence into the next round of learning. We present NeoHorse-1, a family of agent-native models developed to explore this path through agentic post-training. Our system combines a heterogeneous model pool with intelligent routing, recording the predicted capability demand, selected service tier, and subsequent interaction for each user turn. These records are converted into training examples that preserve interleaved reasoning, tool calls, and harness context, and are admitted through structural validation, six-dimensional semantic evaluation, and subscene-level labeling. Routing signals organize supervised fine-tuning into a three-stage curriculum and extend to routing-guided on-policy distillation, where a teacher supervises student-generated responses under the same progression. Capability-guided allocation then converts evaluation feedback into the next training mixture, closing an evaluation-selection-update loop in which what the system learns to do shapes what it learns from next. Across eleven benchmarks covering harness-based agents, tool use, coding, and instruction following, post-training raises the macro-average from 58.94 to 64.87 at 4B and from 65.60 to 69.04 at 9B, substantially narrowing the aggregate gap between the post-trained 4B model and the 9B base model. NeoHorse-1 provides an initial prototype of this feedback-driven process and a path toward harness-mediated RSI across successive iterations.

- **研究动机**：递归自我改进（RSI）被视为 AI 发展的关键方向，其吸引力在于一旦模型改进本身部分自动化，每一代模型就能为下一代做出贡献，使训练过程不再受限于人工整理的数据与监督。

## 2. 方法论

### 2.1 核心思想

- 将异构模型池与智能路由相结合，记录每个用户轮次的**预测能力需求**、**所选服务层级**与**后续交互**。
- 这些记录被转化为用户轮次训练样本，保留交错的推理、工具调用和 Harness 上下文。
- 路由信号既用于组织监督微调课程，也用于调度在线蒸馏的起始上下文。
- 能力引导分配将评估反馈转化为下一轮训练混合数据，形成闭环。

### 2.2 数据构造与质量准入

- **三级粒度组织**：轨迹（完整交互）→ 用户轮次（基本序列化训练单元）→ 子场景（共享局部目标的相邻轮次，语义标注单元）。
- **数据来源**：主语料为约 10⁵–10⁶ 条 Harness 生成轨迹，辅以公开指令、推理、工具使用、代码与偏好数据。
- **结构验证**：规则化检查请求/响应存在性、因果事件顺序、工具调用与结果配对闭合性，产出“内部完整”“部分可恢复”“隔离”三种状态。
- **六维语义评估**：目标达成、指令遵循、工具使用、证据一致性、错误恢复、终止，每维取 PASS/WARN/FAIL/NOT_EVALUATED，不将缺失证据转为正面判定。
- **子场景级标注**：沿 Scene（场景）、Goal（目标）、Outcome（结果）三轴刻画，连接用户意图、智能体执行与可验证结果。
- **路由信号**：路由器在用户轮次级别估计能力需求，分配 C0–C3 四个服务层级，保留原始预测、策略调整后决策与实际服务层级，形成“预测—动作—结果”记录。

### 2.3 智能体监督（SFT）

- **训练单元**：一个用户轮次及其历史上下文；监督当前轮次内保留的助手目标片段（推理、工具调用及参数、可见响应、响应结束标记）。
- **上下文策略**：保留当前轮次推理，省略历史轮次推理；历史用户请求、可见助手响应、工具调用与结果保留为上下文；系统指令、工具规格等非助手片段不参与预测损失。
- **SFT 目标**：对批次 B 中所有被监督 token 做交叉熵最小化，按监督 token 总数归一化，而非按序列长度或轮次数。

### 2.4 路由引导课程学习

- 使用路由器估计的能力需求组织 SFT 示例顺序，采用 C0–C3 能力排序。
- **硬排序**：直接使用分配层级索引 \(k_i\)；**软排序**：使用得分加权平均层级索引 \(s_i = \sum_{k=0}^{3} k \pi_{i,k}\)。
- 训练分三阶段，每阶段约含三分之一示例，逐步引入更高路由分数的示例，同时将部分低分示例保留到后续阶段，防止训练末期被高需求交互主导。
- 每遍训练中每个示例使用一次，全程使用相同掩码 SFT 目标，阶段间不重置优化器或学习率调度。

### 2.5 路由引导在线策略蒸馏（OPD）

- 使用助手响应前的记录上下文作为生成起点，按相同三阶段分配调度上下文批次分布 \(\rho_j\)。
- 学生检查点从上下文生成一个助手响应，固定教师提供下一 token 分布；保留学生 rollout 的 top-\(K\) 候选 token 与剩余概率质量 bin，对齐后计算响应归一化反向 KL。
- 仅更新学生，rollout 检查点随训练刷新，使后续上下文获得教师对更近期学生行为的监督。

### 2.6 能力引导数据分配

- 每个迭代，当前模型检查点在分层评估套件（与训练去污染隔离）上评估，按属性、质量维度、结果状态与路由层级聚合为模型缺陷画像。
- 缺陷画像将下一轮训练混合数据转向表现不足的区域，同时保持广泛覆盖；成功轨迹提供正监督，信息性失败识别需补充覆盖的区域。
- 不引入独立的失败专用目标，而是改变训练数据组成。

## 6. 主要结论与发现

- **两个规模均获广泛提升**：4B 宏平均从 58.94 升至 64.87，9B 从 65.60 升至 69.04；4B 在多数基准上超越 Qwen3.5-4B，9B 在多数基准上超越 Qwen3.5-9B。
- **增益集中于交互与执行密集型任务**：Harness 智能体任务、工具调用、挑战性编码提升显著；指令遵循相对稳定。
- **规模仍然有益**：9B 始终优于 4B，额外增益集中在需持续状态追踪、外部工具交互、基于执行反馈修正决策的任务；4B 后训练模型已能在若干基准上匹配或超越 9B 基座。
- **轨迹行为差异**：后训练模型能组织更完整的工作流（证据获取、约束修订、验证、产物交付）；更大模型更擅长迭代验证、失败恢复、策略适应，且能更高效利用交互预算（PinchBench 案例中请求数、执行时间、token 用量分别减少约 70.8%、76.7%、83.6%）。
- **路由 Harness 数据优于公开数据**：在相同课程配置下，五个基准平均提升 6.26 分，HumanEval +8.54、\(\tau^2\)-Bench +11.31。
- **监督规模缩放有效**：开发套件平均分从基线 69.31 稳步升至 71.45（最大数据规模）。
- **RSI 循环初步验证**：后训练模型返回异构模型池，新轨迹、路由记录与能力反馈可在同一数据管线中为下一轮训练播种。

## 7. 优点

- **机制创新**：将已部署的 Routing Harness 重新定义为 RSI 的观测与反馈来源，而非仅作为服务层，思路新颖且具有实践基础。
- **数据管线系统化**：三级粒度组织、结构验证、六维语义评估、子场景标注、路由信号对齐，形成可复用的数据准入与刻画框架。
- **课程设计巧妙**：用路由预测的能力需求而非实际服务模型身份作为难度代理，避免用户覆盖、服务可用性等部署因素污染难度标签；软排序可区分同层级示例。
- **方法衔接自然**：SFT 课程与 OPD 上下文调度共享同一路由引导三阶段进展，SFT 学习记录响应，OPD 在学生学习前缀上提供教师监督，两者互补。
- **闭环设计完整**：能力引导分配将评估反馈转为下一轮数据混合，改变数据组成而非引入独立目标，简洁且可扩展。
- **实验控制较严格**：数据消融中初始化、课程、优化器、种子、packing、评估协议均匹配，去污染机制确保训练评估分离。
- **轨迹分析与案例研究**：不仅报告分数，还通过具体轨迹揭示行为机制差异，增强结论可信度。

- **数据构造依赖特定 Harness**：主语料来自特定 Routing Harness 的交互轨迹，其工具接口、上下文格式与任务分布可能与更广泛部署环境不同，迁移性未经检验。
- **未讨论安全性与对齐风险**：RSI 循环中模型行为可能随迭代漂移，论文未涉及能力评估之外的稳定性、可控性或价值对齐监测机制。
- **失败样本利用方式较粗**：能力引导分配仅通过改变数据混合比例来吸收失败信号，未区分失败类型（如工具调用错误、推理错误、终止错误）并设计针对性监督，可能限制缺陷修复效率。
- **子场景标注成本与一致性未量化**：语义标注依赖人工或模型辅助，论文未报告标注者间一致性、标注成本或自动化程度，影响管线可扩展性判断。
- **OPD 教师选择与固定策略未详述**：在线策略蒸馏中教师的来源、是否固定、教师与学生能力差距如何影响蒸馏效果等关键设计细节未充分展开。
- **长期在线部署验证缺失**：实验均为离线基准评估，未展示 NeoHorse-1 在真实路由 Harness 中持续运行、收集新轨迹并触发下一轮训练的实际闭环效果。

## 9. 总体评价

NeoHorse-1 是一篇在**机制层面**具有明确创新性的工作。其核心贡献不在于提出全新的训练目标或网络架构，而在于将已部署的 Routing Harness 从单纯的服务基础设施重新概念化为**递归自我改进的观测与反馈通道**：路由预测、服务层级选择与后续交互结果共同构成“预测—动作—结果”记录，这些记录既用于组织监督微调课程，也用于调度在线蒸馏上下文，并通过能力引导数据分配将评估反馈注入下一轮训练混合数据。这一思路将 RSI 从抽象愿景拉回到可操作的工程管线，具有较强实践启发性。

方法设计上，论文展现了较好的系统性：数据侧建立三级粒度组织、结构验证与六维语义评估；训练侧以路由预测能力需求为难度代理构建三阶段课程，并让 SFT 与 OPD 共享同一进展调度；闭环侧以模型缺陷画像驱动数据组成调整，而非引入额外目标函数。实验方面，两个规模、十个基准的主结果一致显示后训练带来广泛提升，增益集中于交互与执行密集型任务；数据消融表明路由 Harness 轨迹优于公开合成数据；缩放实验显示监督规模与性能正相关；轨迹分析进一步揭示了行为机制差异。

然而，论文的**核心主张“递归”尚未被实证**：实验仅完成单次 RSI 迭代，未展示多代累积改进。算力信息缺失、部分基线来源不统一、若干基准单次运行、评估仅限文本模态等限制，也削弱了结论的稳健性与可复现性。此外，路由信号校准、失败样本精细利用、安全对齐监测等关键环节仍有待深化。

总体而言，NeoHorse-1 为 RSI 提供了一条**以部署基础设施为观测面、以数据管线为闭环载体**的可行路径，其价值更多在于机制示范与工程框架，而非最终验证递归自我改进的完整愿景。后续若能在多代迭代、跨 Harness 迁移、安全监测与算力透明化方面补强，将显著提升该路线的说服力与影响力。
