## 摘要
大型语言模型（LLM）智能体可以从以往任务经验中蒸馏出的可复用技能中受益，但现有的技能优化方法往往依赖昂贵的基于执行的评估和大量任务数据。我们提出 COBRA-Skills，一个高效框架，将技能优化形式化为在动态演化候选空间上的预算受限序贯优化。COBRA-Skills 将上下文赌博机引导的优先级排序与基于证据的技能演化相结合，有选择地将评估分配给有前景或信息量大的候选技能，同时根据执行反馈持续改进技能种群。在六个异构智能体基准和三个目标模型上，COBRA-Skills 在对比方法中始终取得最强的平均性能，同时相对于 SkillOpt 将优化成本降低 55%–58%，且每个基准仅使用 50 个唯一优化示例。进一步分析表明，COBRA-Skills 对智能体运行框架（agent harness）的变化保持稳健，并且在目标模型本身用于技能生成和精炼时也能有效运行。

## Abstract
Large language model (LLM) agents can benefit from reusable skills distilled from prior task experience, yet existing skill optimization methods often rely on costly execution-based evaluation and substantial task data. We introduce \textbf{COBRA-Skills}, an efficient framework that formulates skill optimization as budgeted sequential optimization over a dynamically evolving candidate space. COBRA-Skills couples contextual-bandit-guided prioritization with evidence-grounded skill evolution, selectively allocating evaluations to promising or informative candidates while continually refining the skill population from execution feedback. Across six heterogeneous agent benchmarks and three target models, COBRA-Skills consistently achieves the strongest average performance among compared methods, while reducing optimization cost by 55--58\% relative to SkillOpt and using only 50 unique optimization examples per benchmark. Further analyses show that COBRA-Skills remains robust to changes in the agent harness and performs effectively when the target model itself is used for skill generation and refinement.

## 2. 方法论
- **核心思想**：把每个候选技能视为上下文赌博机中的“臂”，用技能语义嵌入表示，用目标智能体执行反馈作为奖励；在有限轮次内，优先评估“预测收益高”或“探索价值高”的技能，并周期性用执行证据进化技能种群。
- **技能表示与奖励预测**：
  - 技能 \(s\) 经固定嵌入模型 \(\phi\) 得到语义表示 \(z_s=\phi(s)\)。
  - 用轻量两层 MLP \(f_\theta\) 从 \(z_s\) 预测奖励，损失为带 \(\ell_2\) 正则的均方误差：
    \[
    L(\theta)=\frac{1}{|H_t|}\sum_{(s_i,z_i,r_i)\in H_t}(f_\theta(z_i)-r_i)^2+\beta\|\theta\|_2^2
    \]
- **LinearUCB 探索**：
  - 加入置信奖励：
    \[
    b_t(z_s)=\nu\sqrt{z_s^\top A_{t-1}^{-1}z_s}
    \]
  - 其中 \(A_{t-1}=\lambda I+\sum_{i=1}^{t-1}z_{s_i}z_{s_i}^\top\)，\(\nu\) 控制探索强度。
  - 未探索或语义区域不熟悉的技能获得更大 bonus。
- **优先级分数**：
  \[
  U_t(s)=f_{\theta_{t-1}}(z_s)+b_t(z_s)
  \]
  - 每轮选择 \(U_t(s)\) 最高的技能交给目标智能体评估。
  - 该分数也用于种群更新时剪枝低优先级技能。
- **算法流程**：
  1. 初始化优化集 \(D_{\text{opt}}\)、无技能轨迹 \(T_0\)、初始技能种群 \(P_1\)；历史 \(H_0=\emptyset\)，设计矩阵 \(A_0=\lambda I\)。
  2. 每轮对种群中每个技能计算嵌入和优先级分数。
  3. 选择最高优先级技能，在 \(D_{\text{opt}}\) 上评估，得到奖励 \(r_t\) 和轨迹 \(T_t\)。
  4. 更新历史 \(H_t\)、设计矩阵 \(A_t\)，并重新拟合神经网络奖励预测器。
  5. 若达到周期性进化条件，则执行 `EVOLVE`；否则种群不变。
  6. 最终返回历史中平均奖励最高的技能。
- **证据驱动技能进化**：
  - 周期性按更新后的优先级分数剪除最低的 \(m\) 个技能，再用新候选补充。
  - **Regeneration**：从原始无技能轨迹 \(T_0\) 独立生成新技能，引入新搜索方向。
  - **Rollout Mutation**：基于当前轮被评估技能的成败轨迹，对父技能做局部保守修正。
  - **Crossover**：当已评估技能足够多时，将技能分为高/低性能组；以强技能为骨架，其他强技能提供正证据，弱技能提供负证据，进行性能导向重组。
- **最终选择**：返回优化历史中平均奖励最高的技能，而非最后一次生成的技能。

## 3. 实验设计
- **Benchmark / 场景**：六个异构智能体基准：
  - SearchQA：开放域问答。
  - SpreadsheetBench：真实 Excel 表格操作。
  - DocVQA：文档图像视觉问答。
  - LiveMathematicianBench：研究级数学推理。
  - SocialMaze：社会推理，使用 Hidden Role Deduction 任务。
  - ALFWorld：交互式文本具身任务。
- **任务设置**：SpreadsheetBench 和 ALFWorld 为多轮，最多 30 轮交互；其余多为单轮。SocialMaze 使用官方 soft score：0、0.5、1。
- **目标模型**：Qwen3.6-35B-A3B、GPT-5.4-Nano、Gemma-4-26B-A4B-it。
- **嵌入与教学模型**：固定嵌入模型 Qwen3-Embedding-4B；默认教学模型 GPT-5.5，medium reasoning effort；目标模型禁用显式推理/思考。
- **对比方法**：
  - No Skill：无外部技能。
  - LLM Skill：仅用证据驱动再生生成技能，不再优化。
  - Trace2Skill：从执行轨迹蒸馏可复用技能。
  - SkillOpt：基于目标智能体执行反馈迭代优化技能。
- **评估协议**：
  - 所有方法共享同一 held-out 测试集，100 个样本。
  - Trace2Skill 和 SkillOpt 使用较大优化池；COBRA-Skills 每基准仅用 50 个唯一优化示例。
  - COBRA-Skills 运行 \(T=30\) 轮，种群大小 \(K=10\)，每次进化剪枝 \(m=3\)。
  - 默认超参：\(\nu=0.1\)、\(\lambda=0.03\)、\(d=3\)、\(\eta=0.35\)。
  - 主要结果取三次独立运行的平均
