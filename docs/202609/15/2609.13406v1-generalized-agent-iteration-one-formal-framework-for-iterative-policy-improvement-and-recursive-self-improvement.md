## 摘要
当我们谈论递归自我改进（RSI）时，我们谈论的是一种现象、一种机制，还是一种前景？在迈向自主且不断演化的智能的过程中，RSI 正在众多尺度上被宣称，然而尚不存在一个能形式化描述这些新兴实例的统一框架。其在经典领域中的对应物——迭代策略改进——由广义策略迭代（GPI）刻画，这是一个适用性广泛、理论性质已被充分理解的框架，但仅限于更新原则和评估基础位于智能体之外的情形。在本文中，我们提出广义智能体迭代（GAI），这是一个形式化框架，将迭代策略改进和 RSI 描述为同一学习范式的两种情形。GAI 将智能体定义为一个系统内可修改组件的配置，并将学习过程建模为智能体评估与智能体改进的循环。两个关键调节维度随后区分这些实例：改进机制是否是智能体的一部分，以及衡量它所依据的标准是否植根于智能体之外。前一个维度划定了 GPI 与 RSI 之间的边界，后一个维度决定了系统的极性属于锚定、目标漂移或完全自指。此外，我们使用这些坐标将现有系统置于相同的两个轴上，并使递归自我改进的缺陷能够以每次一个条件的方式加以陈述。我们将本文视为探索 RSI 形式化刻画的第一步，该刻画立足于经典论述，使现有系统具有可比性，并为分析和设计新系统提供有原则的基础。

## Abstract
When we speak of recursive self-improvement (RSI), are we speaking of a phenomenon, a mechanism, or a prospect? Towards autonomous and evolving intelligence, RSI is being claimed at many scales, while no single framework that formally describes these emerging instances exists. Its counterpart in the classical realm, iterative policy improvement, is characterized by generalized policy iteration (GPI), a framework of broad applicability with well-understood theoretical properties, but only where the update principle and the evaluation base lie outside the agent. In this paper, we propose Generalized Agent Iteration (GAI), a formal framework that describes iterative policy improvement and RSI as two cases of a single learning paradigm. GAI defines the agent as a configuration of modifiable components within a system and models the learning process as a cycle of agent evaluation and agent improvement. Two pivotal dials then distinguish the instances: whether the improving mechanism is part of the agent and whether the standard it is measured against is grounded outside it. The former dial delineates the boundary between GPI and RSI, and the latter determines a system's polarity as anchored, goal drift, or fully self-referential. Moreover, we use these coordinates to place existing systems on the same two axes and make the defects of recursive self-improvement statable one condition at a time. We see this paper as a first step toward exploring a formal characterization of RSI that rests on the classical account, makes existing systems comparable, and provides a principled basis for analyzing and designing new ones.

## 2. 方法论

### 核心思想
- 提出 **Generalized Agent Iteration（GAI）**，保持 GPI 的“评估—改进”交替循环，但将**改进机制本身**纳入可修改范围。
- 将智能体定义为系统内**可修改组件的配置**，学习过程建模为 **智能体评估** 与 **智能体改进** 的循环。

### 关键定义
- **系统**：χ = (π, V, m, U, ρ) 五元组：
  - π：策略（S → Δ(A)），选择世界动作；
  - V：行动评论家（S → R），评价 π 的表现；
  - m：修改器（X → Δ(X_Ag)），提出系统如何改变；
  - U：修改评论家（X → R），评价所提改动是否服务于目标 G；
  - ρ：**评估基准**，评论家所依据的标准。
- **智能体 Ag ⊆ O**：系统中可修改组件的集合；智能体实例 ξ ∈ X_Ag；χ[ξ] 表示替换智能体部分后的系统。
- **GAI 迭代**：
  - *智能体评估*：评论家依据 ρ 对智能体打分（V 在策略层，U 在智能体层）；
  - *智能体改进*：修改器产生新实例 ξ ~ m(·|χ)，系统采纳 χ ← χ[ξ]。

### 两个调节维度（Two Dials）
- **Dial 1 — 改进机制是否属于智能体**：
  - m ∉ Ag：改进机制外部固定，即 GPI；
  - m ∈ Ag：系统可重写自身修改器，递归闭合于 m，无外部元层，即 RSI。
- **Dial 2 — 评估标准是否外在于智能体（是否有根基）**：
  - **锚定（Anchored）**：ρ 内容来自外部（世界与目标），且 ρ ∉ Ag，智能体不可改写；
  - **目标漂移（Goal Drift）**：ρ 仍有外部内容，但 ρ ∈ Ag，智能体可改写；
  - **完全自指（Fully Self-Referential）**：ρ 无外部内容，循环仅受内部自一致性约束。

### 公式与流程
- 目标函数：χ⋆ ∈ argmax_χ E[Σ γ^t r(S_t, A_t) | χ]，由世界与目标固定，非系统自定。
- **GPI 实例**：Ag = {π, V}，m ∉ Ag，内容固定为评估算子 E_m 与改进算子 I_m：
  - V ← E_m(V, π; ρ_V)，π ← I_m(V)，m 本身不变；ρ_V 以世界奖励 r 为内容。当 E_m 为策略评估、I_m 为贪心时即为策略/价值迭代，有限 MDP 下收敛到最优策略 π⋆。
- **RSI 实例**：m ∈ Ag，典型 Ag = {π, V, m, U}：
  - 策略更新：V ← E_m(V, π; ρ_V)，π ← I_m(V)；
  - 智能体更新：ξ ~ m(·|χ)，χ ← χ[ξ]，m′ ← (ξ)_m，U′ ← (ξ)_U，下一修改器与评论家由当前修改器产生。
- **参考理想（自一致性条件）**：
  - 评估：U(χ) = E_{ξ~m}[ρ_U(χ, ξ) + γU(χ[ξ])]；
  - 改进：supp m(·|χ) ⊆ argmax_ξ [ρ_U(χ, ξ) + γU(χ[ξ])]。
  - 这两条是**刻画条件而非强制更新**，无外部机制保证其成立。

## 6. 主要结论与发现

- **统一性结论**：GPI 与 RSI 是同一个“评估—改进”交替循环的两种设置，仅由两个 dial 区分；GPI 是“修改器在智能体之外、基准锚定”的实例。
- **极性三态**：Dial 2 决定系统极性为**锚定 / 目标漂移 / 完全自指**；当前多数已演示系统落在锚定行，后两行主要由边界案例与立场论文代表。
- **四个缺陷**（与 GPI 条件一一对应，见 Table 4）：
  1. **候选自我的搜索**（Dial 1: m ∈ Ag）：改进步骤是无限内容空间上的 argmax，不再廉价且单调——违反“改进廉价且单调”；结构性 + 已观察。
  2. **自评估**（Dial 1: U ∈ Ag）：被评对象与评估工具重合，所报价值本身可被修改——违反“评估者独立于被评对象”；结构性。
  3. **无根基基准**（Dial 2: ρ_U 无根基）：自一致性条件只约束 (m, U)，不指涉目标 G，既不唯一也不保证忠实性，类比 delusion box；结构性。
  4. **目标漂移**（Dial 2: ρ_U ∈ Ag）：目标名义不变而度量机制可变，系统报告进展却未必跟踪目标（Red Queen Gödel Machine 为实例）；结构性 + 已观察。
- **开放性目标**：自一致性条件解集未刻画；RSI 到 GPI 的归约仍是散文而非带显式假设的命题；系统内部监视器能否判定自身忠实性仍待解决（预期需要自指论证）。
