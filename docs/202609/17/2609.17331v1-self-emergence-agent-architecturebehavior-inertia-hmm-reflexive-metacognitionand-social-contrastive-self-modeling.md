## 摘要
大语言模型（LLM）智能体展现出强大的语言生成与问题求解能力，却受限于三种结构性局限：人格漂移、非进化式反思，以及自我—他者边界的缺失。现有的生成式智能体仿真依赖静态记忆和固定提示，既不能维持行为惯性，也不能实现内源性自我演化。我们提出自我涌现智能体架构（SEAA），它整合了三个组件：(i) 一个隐马尔可夫模型（HMM），将长期行为与认知惯性编码为可编辑的状态转移矩阵；(ii) 一个Reflexion风格的言语元认知循环，其输出会更新HMM参数本身，而不仅仅被存储为文本；(iii) 一个多智能体社会环境，其中最初相同的智能体会持续将自身行为与他人行为进行比较。三个组件构成闭环：社会行动 → 反馈 → 自我反思 → 惯性更新 → 差异化行动。我们提出三个可证伪假设，并提供带有可操作指标的可复现实验方案。一个不依赖语言模型的原型表明，该循环会自发打破对称性：最初相同的智能体会巩固出不同且稳定的人格，而匹配对照组则不会。使用托管LLM进行的实验将这些差异显现为不同的第一人称自我叙事，而五智能体审议会自发形成社会结构——一个共识中心和一个被一致拒绝的离群者——这在对照组中并不存在。受庄子启发，遵循认识论上不可知论的立场，SEAA仅研究可观察的行为涌现，不对主观感受质（qualia）作出任何主张。这项工作贡献了一个统一框架、一个带有伪代码的具体架构、机制性证据，以及一个用于研究人工自我涌现的显微镜式沙盒。

## Abstract
Large language model (LLM) agents exhibit strong language-generation and problem-solving capabilities, yet suffer from three structural limitations: personality drift, non-evolutionary reflection, and the absence of a self-other boundary. Existing generative-agent simulations rely on static memory and fixed prompts, maintaining neither behavioral inertia nor endogenous self-evolution. We propose the Self-Emergence Agent Architecture (SEAA), which integrates three components: (i) a Hidden Markov Model (HMM) that encodes long-term behavioral and cognitive inertia as an editable state-transition matrix; (ii) a Reflexion-style verbal metacognition loop whose output updates the HMM parameters themselves, rather than merely being stored as text; and (iii) a multi-agent social environment in which initially identical agents continuously compare their behavior with others'. The three components form a closed loop: social action $\to$ feedback $\to$ self-reflection $\to$ inertia update $\to$ differentiated action. We state three falsifiable hypotheses and provide a reproducible experimental protocol with operational metrics. A language-model-free prototype shows the loop spontaneously breaks symmetry: initially identical agents consolidate distinct, stable personalities whereas matched controls do not. Experiments with a hosted LLM surface these differences as distinct first-person self-narratives, and a five-agent deliberation spontaneously develops social structure---a consensus hub and a unanimously rejected outlier---absent in the control. Following an epistemologically agnostic stance inspired by Zhuangzi, SEAA studies only observable behavioral emergence and makes no claim about subjective qualia. This work contributes a unified framework, a concrete architecture with pseudocode, mechanistic evidence, and a microscope-style sandbox for studying artificial-self emergence.

## 1. 核心问题与整体含义

- **研究动机**：LLM 智能体虽具备强大的语言生成与问题求解能力，但在模拟"个体化、发展中的自我"时存在三大结构性瓶颈：
  - **缺乏稳定的个体惯性**：基础 LLM 反映的是全局语料平均分布，没有持久内部状态，人格随提示漂移，无法体现跨时间一致性。
  - **反思不改变自我**：主流反思框架（如 Reflexion）仅将自然语言总结存入上下文记忆以改进下一任务，从不修改智能体的底层行为倾向——智能体能"总结经验"，却不能"改变自己是谁"。
  - **缺乏内源性自我—他者边界**：现有多智能体仿真实现了行为交换，但没有机制让智能体区分自我与他人。人类自我概念并非天生，而是在长期社会比较与行为差异识别中涌现。
- **整体含义**：论文试图将"自我"从抽象哲学概念转化为可计算、可编辑、可观测的行为动力学对象，构建一个研究"人工自我涌现"的显微镜式实验沙盒。
- **哲学立场**：受庄子"子非鱼，安知鱼之乐"启发，采取认识论不可知论——只研究可观察的行为涌现（矩阵分化、一致性、对比性自我描述），不主张也不否认主观感受质（qualia）。

## 2. 方法论

### 2.1 核心思想
SEAA 将三个组件耦合为闭环：**社会行动 → 反馈 → 自我反思 → 惯性更新 → 差异化行动**。关键在于反思不仅被存储为文本，而是**结构化地编辑智能体的行为惯性参数本身**。

### 2.2 五大模块

| 模块 | 功能 |
|------|------|
| HMM 惯性模块 | 以隐马尔可夫模型编码长期行为/认知惯性 |
| 反思性元认知模块 | Reflexion 风格言语反思，输出映射为参数更新 |
| 私有自传体记忆 | 仅存自身经历、行动、反思，排除共享"平均"语料 |
| 多智能体社会环境 | N 个初始相同智能体互动，暴露彼此可观察行为 |
| 自我模型更新器 | 定期用近期记忆与反思重写自然语言自我模型 M_t |

### 2.3 关键技术细节

- **HMM 惯性建模**：离散隐状态集 S = {s₁,...,s_K}（如 calm, alert, impulsive, pessimistic），标准转移概率 P(z_{t+1}=s_j | z_t=s_i) = [P_t]_{ij}。与静态 HMM 不同，SEAA 使 P_t **时变**。

- **反思→参数更新公式**（论文核心数学表达）：
  - **P_{t+1} = Normalize(P_t + η · Δ(R_t))**
  - 其中 Δ(R_t) 是从反思文本解析出的方向矩阵，η 为小学习率，行归一化保持随机性。这是"反思改变自我"的数学所在。

- **机制原型的数值实现**：
  - 转移矩阵由基础惯性与当前偏好重建：**P_t = softmax(log P_base + βV_t)**，P_base 对角占优。
  - 反思信号基于行为与自身"经验需求" n_t 的契合度：**r_t = cos(b_{z_t}, n_t) − 0.80 + ε_t**
  - 偏好更新：**V_{t+1}[z_t] = clip(V_t[z_t] + η·tanh(2r_t))**——反复契合的经验被强化，形成正反馈使 P_t 收敛到主导状态。
  - 每个智能体的 n_t 走独立随机路径，因此不同智能体强化不同状态，实现**自发对称破缺**。

- **元认知四问**：(1) 行动是否符合我的惯性？(2) 哪种惯性倾向驱动了决策，是否有偏？(3) 该倾向应如何调整？(4) 对 P_t 的对应结构化编辑是什么？其中第 (4) 项"语言到参数的映射"是核心工程创新与主要技术风险。

- **伪代码流程**：每个智能体初始化相同的均匀随机转移矩阵与空记忆 → 每步执行 HMM 状态转移 → 检索记忆生成行动 → 环境执行并反馈 → 反思 → 更新 HMM 参数 → 重写自我模型。

### 2.4 三个可证伪假设
- **H1（个体分化）**：初始相同的智能体在社会环境中，其 HMM 转移矩阵随不同经历而分化，两两行为相似度单调下降。
- **H2（反思驱动演化）**：反思更新 HMM 参数的智能体比仅存文本的对照智能体适应环境变化更快、人格更稳定。
- **H3（社会对比边界）**：多智能体社会中的智能体在自我描述中逐步明确自我—他人区分；孤立对照不会。

## 3. 实验设计

### 3.1 数据集 / 场景
- **无语言模型机制原型**：K=4 隐状态，D=3 行为维度（合作性、冒险性、表达性），N=5 智能体，T=600 步，30 个随机种子。
- **真实 LLM 实验**：使用 DeepSeek-Chat 托管 API，温度 0.8（访谈与审议）、0.2（提名），通过环境变量读取密钥。
- **场景**：
  - 一对一自我访谈（3 个问题：你是谁？你与他人有何不同？是否有经历改变了你？）
  - 五智能体圆桌审议（资源短缺 vs 远距离风险资源区的 go/stay 决策）

### 3.2 Benchmark / 对照
- **核心对照条件**：文本-only 反思（Reflexion 风格）——反思在每个时间步生成并记录，但**从不编辑内部参数**。这与 SEAA 条件（反思编辑 HMM）形成直接机制级对比，而非简单开关。
- 另设孤立对照（无社会互动）。
- 与相关工作的定位对比（Table 1）：ReAct、Reflexion、Generative Agents、Adaptive HMM、MECoT、Generative Life Agents、Takata et al. 等，SEAA 是唯一同时具备可编辑惯性、反思→参数、相同起点涌现人格、社会对比自我模型的工作。

### 3.3 主要实验
1. **实验 1（H1）**：5 智能体自由互动 ≥500 步 vs 5 智能体孤立对照；指标包括行为相似度（余弦）、矩阵分歧（Frobenius 距离）、人格巩固（自距离）。
2. **实验 2（H2）**：2×2 设计（反思是否编辑 HMM × 是否有社会）；注入扰动（资源冲突、新来者）后测适应时间与一致性。
3. **实验 3（H3）**：每 50 步标准化自我访谈；指标包括自我模型嵌入距离、对比性陈述频率、自我模型稳定性。
4. **机制原型**：30 种子群体级分化 + 应急冲击实验 + 学习率消融。
5. **语言层**：确定性 verbalizer + 真实 LLM 自访谈（10 种子）+ 五智能体审议（6 种子）。

## 6. 主要结论与发现

- **自发对称破缺**：机制原型中，初始完全相同（矩阵距离 0.03、偏好全为零）的 5 个智能体，30 种子平均矩阵分歧升至 1.91±0.29（对照恒为 0）；自我模型距离 0.51±0.13（对照 0.13±0.02）；人格确定性 0.84±0.10（对照 0.25）；自我—他者差距 0.35±0.09（对照 0.08±0.01）。平均 2.8/5 智能体锁定不同主导人格，对照锁定率为 0。
- **反思驱动再适应（H2）**：应急冲击后，150 个 SEAA 智能体**100% 放弃**被冲击的主导状态并重新巩固新人格，中位切换时间 152 步，被冲击状态占用率从 0.94 崩至 0.06；对照无变化。确定性短暂下探后恢复至 0.80，体现人格重组。
- **消融的因果性与剂量依赖**：η=0（即文本-only 对照）无分化；矩阵分歧随 η 单调上升并在 η≈0.05–0.1 饱和（0 → 1.07 → 1.91 → 1.99 → 2.04），证明机制既必要又剂量依赖。
- **语言层表达**：真实 LLM 自访谈中，SEAA 智能体产生独特、与画像一致的第一人称叙事并引用数值正确的对比（如冲动型自述"风险 +0.55 高于群体"），对照则自述"平衡、无明显特质"。自访谈平均两两 Jaccard 重叠：SEAA 0.267±0.017 vs 对照 0.391±0.020。
- **社会结构涌现**：五智能体审议中，SEAA 组自发分化出角色（冲动者发起、冷静者调和、警觉者成为规则制定枢纽、两位悲观者主张留守），并形成**一致离群者 + 共识枢纽**的社会拓扑；对照组成语平淡、3/5 回答"none"。SEAA 离群份额 0.77 vs 对照 0.33（p=0.011），"none"回答率 0.00 vs 0.53。

## 7. 优点

- **闭环设计优雅**：将"行为惯性—反思—社会对比"三者整合为单一发展闭环，且强调反思**结构性更新内部状态**而非仅存文本，与 Reflexion 形成清晰机制级对照。
- **可证伪假设 + 操作化指标**：三个假设均给出明确的可测指标与证伪标准，符合科学规范。
- **双层验证策略**：先用无语言模型的数值原型隔离数学核心（排除 LLM 噪声），再用真实 LLM 验证语言层涌现，逻辑清晰。
- **显微镜式可复现性**：全程记录每个智能体每步的隐状态、完整转移矩阵、记忆、推理、行动、反馈、反思与自我模型（JSON 快照），支持事后完整回放；代码、提示词、原始转录均公开。
- **消融与因果证据充分**：η 剂量-响应实验清楚证明分化由反思→参数编辑驱动，而非随机动力学；应急冲击实验直接支持 H2。
- **哲学立场克制**：明确区分行为涌现与主观意识，避免过度拟人化，伦理考量审慎。

## 8. 不足与局限

- **模型简化**：离散状态集小（K=4）、经验轨迹用随机游走建模，而人类人格与生命轨迹是高维且有结构的；作者建议未来引入潜变量与可学习的经验模型。
- **LLM 实验覆盖有限**：所有 LLM 实验仅用**单一模型家族（DeepSeek-Chat）**和**单一审议议题**，观察到的领导者/离群者拓扑可能带有该模型风格偏差；跨模型、跨议题复现被作者列为最重要的下一步。
- **缺乏具身性**：纯文本社会缺少具身与感觉运动回路，而作者承认这可能是更丰富自我的前提。
- **语言→参数映射需调参**：Δ(R_t) 的稳定性需要精细调优，是主要技术风险。
- **无法验证 qualia**：与所有现有工作一样，SEAA 无法确立主观感受质的存在。
- **潜在偏差风险**：审议轮次在原始单次研究中 SEAA 三轮、对照两轮，虽在多种子复制中已统一，但提示词设计、议题选择、人格前缀措辞等仍可能引入人为偏差。
- **应用限制**：当前仅为研究沙盒，尚未展示在真实任务或长期部署中的实用性；若未来出现高度复杂自我导向行为，将引发道德地位与"终止"运行中智能体的伦理问题。
