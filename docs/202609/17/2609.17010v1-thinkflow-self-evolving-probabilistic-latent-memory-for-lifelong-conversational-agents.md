## 摘要
终身对话智能体依赖记忆系统来维持与用户深度、情境感知的交互。然而，现有的显式文本记忆流水线面临严重的信息瓶颈，往往会丢失细微的行为模式和情绪变化。此外，它们通常在部署后保持静态，无法在没有人工反馈的情况下自主适应用户的个人习惯和偏好。然而，认知科学表明，人类纯粹在潜在空间中维持心理模型，并通过预测编码不断对其进行细化。受此启发，我们提出 ThinkFlow，一种面向终身对话智能体的新型端到端潜在记忆框架。ThinkFlow 通过将对话流动态压缩为概率潜在记忆技能，绕过了文本瓶颈，能够自主地将复杂的用户状态整合为解耦的连续向量，且不会产生语义干扰。为突破这一瓶颈，我们引入了测试时演化范式。通过将用于引导初始状态的教师引导潜在对齐与用于持续细化的自监督下一用户话语预测任务相耦合，该框架成功克服了冷启动挑战，并实现了无需标签的终身个性化。在长期对话基准上的大量实验表明，ThinkFlow 显著优于现有主流记忆系统，能够在扩展的多会话交互中提供高度个性化和上下文准确的回复。

## Abstract
Lifelong conversational agents rely on memory systems to maintain deep, context-aware interactions with users. However, existing explicit textual memory pipelines suffer from a severe information bottleneck, often losing subtle behavioral patterns and emotional shifts. Furthermore, being typically static post-deployment, they cannot autonomously adapt to personal habits and preferences without manual feedback. Cognitive science, however, suggests that humans maintain mental models purely in a latent space and continuously refine them through predictive coding. Inspired by this, we propose \textbf{ThinkFlow}, a novel end-to-end latent memory framework for lifelong conversational agents. ThinkFlow bypasses the text bottleneck by dynamically compressing conversational flows into probabilistic latent memory skills, autonomously consolidating complex user states into disentangled, continuous vectors without semantic interference. To break this barrier, we introduce a test-time evolution paradigm. By coupling teacher-guided latent alignment to bootstrap the initial state with a self-supervised next-user-utterance prediction task for continuous refinement, the framework successfully overcomes cold-start challenges and achieves label-free lifelong personalization. Extensive experiments on long-term conversation benchmarks demonstrate that ThinkFlow significantly outperforms prevailing memory systems, providing highly personalized and contextually accurate responses over extended multi-session interactions.

## 2. 方法论

### 2.1 核心思想

- 将连续对话流动态压缩为 **K 个解耦的概率潜在记忆技能（Probabilistic Latent Memory Skills, PLMS）**，分别对应事实、情绪、偏好等不同用户画像维度。
- 通过 **门控潜在巩固器（GLC）** 过滤噪声、控制更新；通过 **上下文感知超对齐器（CAHA）** 弥合历史潜在技能与当前语义上下文之间的分布差距。
- 引入 **自监督测试时演化** 范式，利用“预测用户下一句话”作为免费监督信号，实现部署后的持续、无标签终身学习。

### 2.2 关键技术细节

- **PLMS（概率潜在记忆技能）**：
  - 输入当前轮次的隐藏状态序列 \(E_t \in \mathbb{R}^{L \times D}\)，用可学习技能 \(S \in \mathbb{R}^{K \times D}\) 做交叉注意力。
  - 引入分布保持缩放因子 \(1/\sqrt{c}\)（\(c = L/K\) 为压缩率），防止压缩后方差坍缩为确定性点质量。
  - 通过两个并行线性层输出均值 \(\mu_t\) 和 log 方差 \(\log \sigma_t^2\)，用重参数化技巧采样：\(\hat{S}_{new} = \mu_t + \sigma_t \odot \epsilon\)，\(\epsilon \sim \mathcal{N}(0, I)\)。
  - 用 KL 散度损失 \(L_{KL}\) 将近似后验正则化到标准高斯先验。

- **GLC（门控潜在巩固器）**：
  - 用 MLP 在“新技能 \(\hat{S}_{new}\)”与“旧技能 \(S_{old}\)”的拼接表示上学习**信息增益门** \(g_t \in (0,1)^{K \times D}\)。
  - 用 GRU 核心做条件更新：\(S_t = g_t \odot \text{GRU}(\hat{S}_{new}, S_{old}) + (1 - g_t) \odot S_{t-1}\)。
  - 低门值（如 ≈0.12）表示噪声/无用信息，高门值（如 ≈0.91）表示重要信息，实现优雅遗忘与噪声过滤。

- **CAHA（上下文感知超对齐器）**：
  - 采用超网络，根据当前用户查询 \(x_t\) 的语言特征生成低秩变换矩阵 \(W_{adapt} = W_{down}(x_t) \times W_{up}(x_t)\)，瓶颈秩为 \(r\)。
  - 残差投影得到对齐记忆技能：\(S_{aligned} = S_t + S_t \times W_{adapt}\)。
  - 将对齐技能作为软提示（soft prompt）前置到语言模型，条件化生成过程。

- **自监督测试时演化（两阶段训练）**：
  - **Phase 1：教师引导潜在对齐（解决冷启动）**
    - 教师模型读取完整明文历史 \(H_{<t}\)，输出目标分布 \(P_T(y \mid H_{<t}, x_t)\)。
    - 学生模型仅读取当前查询 \(x_t\) 和潜在记忆技能 \(S_t\)，输出 \(P_S(y \mid S_t, x_t)\)。
    - 损失：\(L_{Phase1} = D_{KL}(P_T \parallel P_S) + \alpha L_{KL}\)。
  - **Phase 2：下一用户话语预测（持续演化）**
    - 从第二个会话起教师模型下线，智能体用记忆技能 \(S_{t+1}\) 和上一轮回复 \(a_t\) 预测用户下一句话 \(x_{t+1}\)。
    - 若预测失败（高交叉熵 \(L_{CE}\)），直接迫使 GLC 门关闭，防止记忆被污染。
    - 引入最小熵置信先验 \(L_{Conf}\) 防止语义坍缩。
    - 损失：\(L_{Phase2} = L_{CE}(x_{t+1} \mid S_{t+1}, a_t) + \beta L_{Conf} + \alpha L_{KL}\)。

- **算法流程（文字说明）**：
  - Phase 1：初始化记忆 \(S_0\)，逐轮用教师分布对齐学生分布，更新学生 LLM（LoRA）及 PLMS/GLC/CAHA。
  - Phase 2：逐会话、逐轮在线演化，用用户下一句话作为隐式反馈，持续更新记忆模块与 LoRA 参数。

## 6. 主要结论与发现

- ThinkFlow 在 CC、MSC、GC 上**一致取得最优或接近最优的生成性能**，Mauve 指标提升尤为显著，表明回复更连贯、更接近人类。
- 在 PersonaMem 上，ThinkFlow-8B 取得**最高平均准确率**，在 1M 上下文下甚至媲美或超越 GPT-4o-mini、Claude3.7-Sonnet、Llama3.1-405B、Gemini2.0-Flash 等模型。
- t-SNE 可视化显示潜在记忆空间对不同认知任务（如 Shared Facts 与 Track Evolution）形成**清晰的结构分离**，静态事实密集聚类，动态演化呈连续流形。
- 增加潜在记忆技能数量 \(K\)（从 1 到 10）可**持续提升准确率**，在 1M 超长上下文下提升尤为显著。
- 效率方面，ThinkFlow 消耗 token 最少（2,857），推理时间最短（12.1s），而 MemTree、A-Mem 等显式方法生成数万隐藏 token，耗时近 8 倍。
- 案例研究表明，ThinkFlow 能平滑跟踪用户情绪从“对时尚感兴趣”到“深陷悲伤”的连续转变，避免显式检索被过时表面事实困住。

## 7. 优点

- **范式创新**：首次系统性地提出端到端潜在记忆框架，绕过显式文本瓶颈，将对话流压缩为解耦的概率技能向量。
- **概率建模**：用均值-方差建模记忆技能的不确定性，重参数化采样 + KL 正则化，避免确定性坍缩。
- **门控巩固机制**：信息增益门与 GRU 结合，有效过滤噪声、优雅遗忘，防止记忆污染。
- **超网络对齐**：CAHA 以低秩变换动态桥接历史潜在技能与当前语义上下文，参数高效。
- **自监督终身学习**：Phase 2 利用“下一用户话语预测”作为免费监督信号，实现无标签、部署后持续个性化。

- **效率优势**：token 与时间开销远低于显式记忆管线，适合实时长期陪伴。
- **实验全面**：多数据集、多 backbone、多基线、多维度分析（消融、缩放、效率、案例），论证较扎实。
