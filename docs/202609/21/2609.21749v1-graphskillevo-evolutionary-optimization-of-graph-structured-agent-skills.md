## 摘要
技能可以通过提供特定于任务的过程性指导来提升大语言模型（LLM）智能体的性能，而技能优化则通过迭代式改进进一步提升其有效性。然而，现有的技能优化方法通常将技能表示为非结构化自然语言指令，这带来了两个关键挑战：1）非结构化技能往往缺乏明确的工作流级指导，并包含大量冗余，使LLM难以执行；2）无约束自然语言技能的巨大搜索空间使技能优化效果不佳。为解决这些挑战，我们提出将技能表示为图结构化的自然语言产物。在图结构化技能中，每个节点表示一个执行步骤及其操作指导，而有向边则编码步骤之间依赖上下文的转移。与非结构化技能相比，图结构化技能能够提供清晰的工作流级指导。此外，所提出的图结构化技能还可以促进技能优化。基于这种结构化表示，我们提出了GraphSkillEvo，一个面向图结构化技能的、基于种群的进化优化框架，具有变异和交叉算子。通过维护多个候选技能并组合有效组件，GraphSkillEvo能够比纯基于LLM的迭代式自我改进更广泛、更全面地探索结构化技能空间。在五个智能体基准上的大量实验表明，GraphSkillEvo持续优于强大的技能优化基线SkillOpt，在GPT-5.4-nano上平均准确率提升4.01%，在GPT-5.4上提升1.76%。我们的代码可在 https://github.com/ruisun7/GraphSkillEvo 获取。

## Abstract
Skills can improve the performance of Large Language Model (LLM) agents by providing task-specific procedural guidance, while skill optimization further improves their effectiveness through iterative refinement. However, existing skill optimization methods typically represent skills as unstructured natural-language instructions, creating two key challenges: 1) Unstructured skills often lack explicit workflow-level guidance and contain substantial redundancy, making them difficult for LLMs to execute; 2) the vast search space of unconstrained natural-language skills makes skill optimization ineffective. To address these challenges, we propose representing skills as graph-structured natural-language artifacts. In graph-structured skills, each node represents an execution step together with its operational guidance, while directed edges encode context-dependent transitions between steps. Compared to unstructured skills, graph-structured skills can provide clear workflow-level guidance. Moreover, the proposed graph-structured skill can also facilitate skill optimization. Building on this structured representation, we introduce GraphSkillEvo, a population-based evolutionary optimization framework with mutation and crossover operators for graph-structured skills. By maintaining multiple candidate skills and combining effective components, GraphSkillEvo enables broader and more comprehensive exploration of the structured skill space than purely LLM-based iterative self-refinement. Extensive experiments across five agent benchmarks demonstrate that GraphSkillEvo consistently outperforms the strong skill optimization baseline SkillOpt, improving average accuracy by 4.01% on GPT-5.4-nano and 1.76% on GPT-5.4. Our code is available at https://github.com/ruisun7/GraphSkillEvo.

# GraphSkillEvo 论文总结

## 1. 核心问题与研究动机

- **背景**：LLM 智能体广泛用于真实任务，技能（skill）作为可复用的提示级自然语言产物，提供任务特定的过程性指导（工作流、领域知识、操作规则、输出约束），且可跨不同 LLM 复用，在模型快速迭代的实践中价值很高。
- **问题**：人工编写或一次性 LLM 生成的技能往往不完整、脆弱，因此出现技能优化研究（如 EvoSkill、Trace2Skill、SkillX、SkillOpt）。
- **现有方法的两大瓶颈**：
  - **执行困难**：技能被表示为非结构化自然语言指令（冗长清单/要点），只提供粗粒度工作流指导，LLM 难以判断当前阶段该用哪条指导、下一步该做什么；对能力较弱的模型（如 GPT-5.4-nano）尤为严重。
  - **优化低效**：缺乏显式结构导致搜索空间庞大且冗余——相似工作流可用多种非结构化文本实现，优化器必须探索大量无实质过程差异的表述变体。
- **核心思路**：借鉴技能与流程图在提供分步过程指导上的相似性，将每个技能建模为**图结构化的自然语言产物**，并在该结构化空间上用种群进化搜索进行优化。

## 2. 方法论

### 2.1 图结构技能表示

- 形式化定义：技能 $s = \langle h_s, g_s \rangle$，由全局指导 $h_s$ 与有向图 $g_s = (V_s, E_s)$ 组成。
  - **全局指导 $h_s$**：跨所有节点/工作流共享的任务描述、通用原则、共享执行模板。
  - **节点集 $V_s$**：$n_s$ 个可复用节点，每个节点是一个执行步骤（如解析目标、检索证据、执行操作、验证答案）及其所需的指令、规则、约束。
  - **边集 $E_s$**：通过 $M$ 个工作流 $\{(c_m, p_m)\}$ 指定。$c_m$ 为适用条件，$p_m$ 为节点有序序列（执行路径）；相邻节点构成有向边，表示上下文相关的步骤转移；不同工作流可共享节点但走不同路径。
- **三点优势**：低冗余（共享指令只写一次）、显式工作流指导（每步对应自包含节点指导）、为优化提供更紧凑的结构化搜索空间。

### 2.2 GraphSkillEvo 进化优化框架

- 目标函数：$\tau_{x,s} = A(x,s)$，$r_{x,s} = R(x,\tau_{x,s})$，$s^\star \in \arg\max_s J_D(s)$；仅优化技能产物，固定 LLM 参数与执行 harness。
- **Step 0 种群初始化**：$P^{(1)} = \{s_i^{(1)}\}_{i=1}^N$，除初始技能外由初始化提示让 LLM 生成多样化图结构技能；在完整验证集 $D_{val}$ 上评估作为适应度。
- **Step 1 训练集执行**：每代从 $D_{train}$ 采样小批量 $B$ 个实例，每个技能执行得到轨迹 $T_i^{(t)}$，并保留至多 $K$ 条失败轨迹 $F_i^{(t)}$ 作为反思信息。
- **Step 2 生成新技能**（三步）：
  - **2.1 算子选择**：从 4 个算子中按轮询（round-robin）选择。
  - **2.2 父代选择**：选择概率 $p \propto 1/(r+N)$，$r$ 为验证适应度排名，偏好高适应度技能。
  - **2.3 技能生成**：变异算子输入父代+失败轨迹，交叉算子输入两个父代，由 LLM 生成完整图结构技能。
- **四个进化算子**：
  - 全局指导变异：基于执行轨迹修订全局指导，保持图结构。
  - 图结构变异：修订节点与边（精炼节点指令、增删节点、调整工作流路径），保持全局指导。
  - 全局指导交叉：重组两个父代的全局指导，保留其中之一的图结构。
  - 图结构交叉：重组两个父代的节点与边，保留其中之一的全局指导。
- **Step 3 种群选择**：在完整 $D_{val}$ 上评估新技能，从当前种群与新生技能中按验证适应度保留 Top-N，迭代 $T$ 代后返回最优技能。
- **图结构校验器**：检查生成技能是否符合图 schema（引用的节点都已定义、每个节点至少出现在一个工作流中），不合格者丢弃重生成，保证进化过程中技能始终良构。
- **参数设置**：种群大小 $N=4$，代数 $T=5$，每代采样 15 个训练实例，最多 5 条失败实例用于反思，算子轮询使用。

## 6. 主要结论与发现

- **整体性能**：GraphSkillEvo 在 13/14 设置中最佳；相对无技能执行，平均提升 15.37%（GPT-5.4 无 harness）、21.86%（GPT-5.4-nano 无 harness）、10.31%（GPT-5.4 Codex harness）；相对 SkillOpt 平均提升 1.76%（GPT-5.4 无 harness）、4.01%（GPT-5.4-nano 无 harness）、1.33%（GPT-5.4 Codex harness）。
- **弱模型收益更大**：nano 上相对 SkillOpt 的增益（4.01%）明显高于 GPT-5.4（1.76%），说明清晰的工作流指导对能力较弱、易被冗长指令困扰的模型帮助更大。
- **过程性任务收益最大**：SpreadsheetBench 提升 10.60%，ALFWorld 提升 3.73%；唯一例外是 GPT-5.4-nano 上的 LiveMath，落后 SkillOpt 0.80%。
- **收敛质量更高**：优化曲线显示 SkillOpt 较早收敛，而 GraphSkillEvo 能持续更新到更优性能。
- **Token 更省**：总量上比 SkillOpt 少用约 24%–27% 的优化 token，同时性能更强。
- **图结构对执行与优化均有贡献**：去除图结构使成功率在 5 个基准上分别下降 4.52/2.50/4.19/1.35/0.75 个百分点；仅靠种群进化而无图结构（71.52→64.08）也不足。

- **跨模型可迁移**：用 GPT-5.4-nano 优化、部署到 GPT-5.4，迁移技能在三个基准上均优于无技能基线且优于迁移的 SkillOpt 技能；Spreadsheet 上迁移版达 71.78，甚至超过直接在 GPT-5.4 上优化的 69.40。

## 7. 优点

- **表示创新**：把技能从"非结构化文本"重构为"全局指导 + 可复用节点 + 多工作流路径"的图结构，同时缓解执行难与搜索空间冗余两个

瓶颈，是一个针对性明确、动机清晰的表示层创新。

- **优化与表示对齐**：进化算子被专门设计为"全局指导变异/交叉"与"图结构变异/交叉"两组，使搜索操作与技能的图结构一一对应，避免在无语义差异的文本变体上浪费预算；这解释了 token 消耗下降与性能提升可以同时发生。
- **工程稳健性**：引入图结构校验器（节点必须已定义、每个节点至少被一个工作流引用），保证 LLM 生成的技能在进化全程良构，避免无效个体污染种群；失败轨迹被显式保留并作为反思输入，使变异有明确的错误信号可依赖。
- **实验设计规范**：统一数据划分（seed=42，与 SkillOpt 对齐）、统一执行模型与 harness、三次重复取均值、5 次独立运行的 Welch t 检验，以及跨模型迁移验证，整体可复现性与公平性较好。
- **结论具有实践指导价值**：明确给出"弱模型收益更大""过程性任务收益最大""技能可跨模型复用"三条可操作结论，并配以优化曲线与 ALFWorld 案例，对实际技能库建设有直接参考意义。

## 9. 对后续研究的启发

- **表示层是技能优化的可行切入点**：在不改动模型参数与执行框架的前提下，仅通过把技能从自由文本重构为"全局指导 + 可复用节点 + 多工作流"的结构，就能同时改善可执行性与搜索效率。这一思路可推广到其他提示级产物（工具使用策略、记忆组织、智能体角色定义）的结构化改造。
- **让算子与结构语义对齐**：将进化算子按表示的两个正交分量（全局指导 / 图结构）分别定义，使变异与交叉具备明确语义边界，是可复用的设计范式；后续可探索"节点级"更细粒度的算子（如仅改写单个节点的指令、仅调整条件边），以及基于失败类型自适应选择算子的策略。
- **失败轨迹作为一等公民**：保留并条件化于失败轨迹进行反思式变异，是把执行反馈转为优化信号的直接通道；后续可研究失败聚类（按错误类型分组）后定向变异，提升样本效率。
- **结构化技能库与迁移**：实验显示技能可跨模型迁移且迁移版有时优于本模型优化版，提示可构建与模型解耦的技能库；进一步可研究技能在不同 harness、不同工具集之间的兼容性与失效模式。
- **效率与规模治理**：ALFWorld 上 token 反超表明图结构存在规模膨胀风险，后续值得引入节点合并、路径剪枝、图规模正则化，或在验证收益不足时回退到更紧凑的表示。
- **评测层面**：建议在更大验证集、更多随机种子下报告结果，并同时给出 token 与墙钟成本、显著性区间，避免小基准上的方差主导结论。

## 10. 一句话总结

GraphSkillEvo 通过把技能从非结构化提示清单重构为"全局指导 + 可复用节点 + 多条条件工作流路径"的图结构产物，并配以与该结构语义对齐的四种进化算子（全局指导/图结构的变异与交叉）及图结构校验器，在 5 个异构基准、2 个 LLM、2 种 harness 的 13/14 设置中取得最优，弱模型与过程性任务收益最明显、优化 token 总量更省，但统计显著性并不普遍、ALFWorld 上开销反超、超参数与图规模治理均未充分探索，算力信息亦缺失。
