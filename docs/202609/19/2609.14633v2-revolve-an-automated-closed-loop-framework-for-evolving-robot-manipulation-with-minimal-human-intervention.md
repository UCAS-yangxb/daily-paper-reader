## 摘要
近年来，数据驱动的机器人操作策略取得了显著进展，大幅提升了任务执行与泛化能力。然而，真实世界部署仍然严重依赖人工进行失败评估、纠正和环境重置，而模型往往无法从失败和纠正经验中持续学习。我们提出 REVOLVE（Robot Evolving via Orchestrated Loops, Verification, and Experience，即通过编排循环、验证与经验实现机器人演化），一种以最少人工干预演化机器人操作的自动化闭环框架。REVOLVE 构建在统一软件平台之上，将数据采集、策略训练与部署、失败恢复以及持续学习集成到单一闭环工作流中。其自动重置与纠正（Automated Reset and Correction，ARC）架构可自动重置环境并进行干预以纠正策略失败。双环演化（Dual-Loop Evolution，DLE）通过将真实世界交互和失败-纠正数据反馈至策略学习，并利用外部失配记忆来改进智能体判断，从而持续提升操作策略与智能体。在四项真实世界操作任务上的实验表明，经过五次迭代后，REVOLVE 将平均策略成功率提升 18.5%，将智能体判断准确率提升 8.5%，同时分别将数据采集和部署测试中的人工工作量减少 94.4% 和 95.1%。这些结果表明，REVOLVE 将真实世界部署转变为一种闭环学习过程，能够持续积累并利用执行经验，从而在显著减少人工干预的情况下实现策略与监督模型的持续演化。

## Abstract
Recent advances in data-driven robot manipulation policies have substantially improved task execution and generalization. However, real-world deployment still relies heavily on humans for failure assessment, correction, and environment reset, while models often fail to continually learn from failures and corrective experience. We present REVOLVE (Robot Evolving via Orchestrated Loops, Verification, and Experience), an automated closed-loop framework for evolving robot manipulation with minimal human intervention. Built on a unified software platform, REVOLVE integrates data collection, policy training and deployment, failure recovery, and continual learning into a single closed-loop workflow. Its Automated Reset and Correction (ARC) architecture automatically resets the environment and intervenes to correct policy failures. Dual-Loop Evolution (DLE) continually improves the manipulation policy and agent by feeding real-world interaction and failure--correction data back into policy learning and using an external mismatch memory to refine agent judgments. Experiments across four real-world manipulation tasks show that, after five iterations, REVOLVE improves average policy success rate by 18.5% and agent judgment accuracy by 8.5%, while reducing human effort in data collection and deployment testing by 94.4% and 95.1%, respectively. These results demonstrate that REVOLVE transforms real-world deployment into a closed-loop learning process that continually accumulates and uses execution experience, enabling continual evolution of both the policy and supervisory model with substantially less human intervention.

## 2. 方法论

### 2.1 核心思想

- REVOLVE 构建在统一软件平台之上，把数据采集、策略训练与部署、失败恢复、持续学习整合进单一闭环工作流，包含三大特性：**协同性**（统一平台与接口）、**低干预**（自动采集/重置/纠正）、**持续演化**（双环机制）。

### 2.2 统一软件平台

- 由三部分组成：面向实验者的交互界面、调度系统、底层机器人学习与控制模块。
- 界面提供三个工作区：数据采集、模型训练、真机推理。
- 调度系统统一管理相机流、数据日志、模型训练与策略推理；底层模块涵盖机器人控制、数据采集、端到端策略执行、纠正与智能体监控。
- 支持在统一环境内连续完成采集→训练→推理→记录测试交互与纠正轨迹，减少工具切换。

### 2.3 ARC（Automated Reset and Correction）架构

- **自动数据采集与重置**：
  - 每回合开始，RGB-D 相机捕获场景点云，经标定外参变换到机器人基座坐标系。
  - 通过欧氏聚类计算每个目标簇的几何中心 \(c_i\)，据此生成抓取、抬升、转移等运动序列。
  - 笛卡尔目标位姿 \(T^*\) 通过逆运动学转换为关节空间命令。
  - 同步记录多视角图像、关节状态与动作；保存后重新扫描场景、执行重置程序，再开始下一回合。
- **推理时失败干预**：智能体持续监控任务进度，若在时刻 \(t_c\) 判定任务无法正常完成，则终止策略控制并切换到确定性纠正控制器 \(\kappa\)：
  - \(a_t = \pi_\theta(o_t),\ t < t_c\)；\(a_t = \kappa(o_t, P_t),\ t \ge t_c\)
  - 其中 \(o_t\) 为观测，\(P_t\) 为为纠正重新获取的场景点云。
- **纠正轨迹拼接**：将失败前的策略段与恢复段拼接为连续轨迹：
  - \(\tau^{corr} = \tau^{policy}_{0:t_c} \oplus \tau^{recovery}_{t_c:T}\)
  - 其中 \(\tau=\{(o_t,a_t)\}_{t=0}^{T}\)，\(\oplus\) 表示时间拼接；验证后的 \(\tau^{corr}\) 加入后续训练数据。
- **LLM 辅助控制程序生成**：针对新任务，LLM 依据任务需求、机器人配置和已有控制示例生成控制代码，由实验者验证后执行。

### 2.4 DLE（Dual-Loop Evolution）框架

包含两个互补循环：

- **纠正演化环（Corrective Evolution Loop）**：
  - 不仅使用失败试验，还同时利用成功 rollout 数据和失败后纠正数据来扩展训练分布。
  - 成功回合完整保留；检测到异常时由确定性恢复控制器从当前状态完成任务，得到 \(\tau^{corr}\)。
  - 数据存入 **Correction Memory Bank**，与已有数据合并：\(D_{k+1} = D_k \cup D^{new}_k\)。
  - 策略更新：\(\theta_{k+1} = \arg\min_\theta \mathbb{E}_{D_{k+1}}[L(\pi_\theta(o_t), a_t)]\)。
  - 失败不再被丢弃，而是转化为有效训练数据。
- **判断演化环（Judgement Evolution Loop）**：
  - 维护 CLIP 索引的 **Mismatch Memory** \(M=\{(e_i, y^H_i)\}\)，\(e_i\) 为误判场景视觉特征，\(y^H_i\) 为人工验证标签。
  - 当智能体预测 \(y^V_t\) 与人工判断 \(y^H_t\) 不一致时，将 \((e_t, y^H_t)\) 加入记忆：\(M_{t+1} = M_t \cup \{(e_t,y^H_t)\}\)，否则保持不变。
  - 对新观测按特征相似度检索历史误判案例，作为额外上下文提供给 VLM，**不更新 VLM 参数**即可持续提升判断可靠性。

## 6. 主要结论与发现

- **自动重置稳定**：四个任务平均重置成功率 98.0%（49/50、48/50、49/50、50/50），足以支撑连续数据采集与多轮策略迭代。
- **策略持续提升**：五轮迭代后平均成功率从 40.0% 提升至 58.5%，平均增益 +18.5%；最大增益出现在 Pour Water（+28%，从 22% 到 50%）。
- **智能体判断持续改善**：平均判断准确率从 72.0% 提升至 80.5%，增益 +8.5%；部分任务早期有轻微波动，但整体随误判案例积累稳步提升。
- **人力大幅降低**：数据采集时间从 8.89 h 降至 0.50 h，减少 94.4%；部署测试人力从 2.67 h 降至 0.13 h，减少 95.1%。
- **优于人工方案**：初始策略成功率人工方案 33% vs REVOLVE 40%；五轮后人工方案 45% vs REVOLVE 58.5%，优势从 7 个百分点扩大到 13.5 个百分点。作者认为 REVOLVE 采集的数据更一致、噪声更低，减少了遥操作中操作者依赖与轨迹偏差。
- **总体结论**：REVOLVE 将真实部署转化为闭环学习过程，在极少人工干预下实现策略与监督模型的共同持续演化。

## 7. 优点

- **系统集成度高**：将数据采集、训练、部署、失败恢复、持续学习统一在一个软件平台与闭环工作流中，降低系统集成与工具切换成本，工程价值明确。
- **失败经验有效利用**：通过 \(\tau^{corr}\) 拼接把失败段与恢复段转化为监督信号，改变了传统“失败即丢弃”的做法，符合持续学习直觉。
- **双环协同设计巧妙**：策略环解决“能否通过部署变好”，判断环解决“改进是否基于可靠经验”，两者互补，且判断环通过外部记忆检索实现无参数更新的持续校准，成本低、易扩展。
- **ARC 结合经典控制与学习**：在结构化工作空间内用确定性控制做重置与纠正，兼顾可靠性与可重复性，同时用 LLM 辅助生成控制程序降低新任务配置成本。
- **量化收益显著且直观**：人力削减 94.4%/95.1%、成功率 +18.5%、判断准确率 +8.5%，指标清晰，四任务一致性较好。
- **明确承认局限**：结论部分主动指出复杂任务仍需人工主导高质量数据采集，为后续工作留出方向。

## 8. 不足与局限

- **任务复杂度有限**：四个任务均为基本操作任务，工作空间结构化、流程明确，方法对长时程、多阶段、接触丰富或开放环境任务的适用性尚未验证。
